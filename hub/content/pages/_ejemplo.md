# Ejemplo de teoría (texto ficticio)

Esta introducción es de muestra. Copia este archivo con el nombre de una sección, por ejemplo
`dashboard.md`, y ejecuta `python manage.py load_pages` para verla en la página.

## Qué es un caso de prueba

Un caso de prueba describe **qué** se verifica, **con qué datos** y **qué resultado** se espera.

- Identificador único, por ejemplo `CP-DEMO-001`.
- Precondiciones y pasos.
- Resultado esperado.

## Buenas prácticas

1. Escribe un caso por comportamiento.
2. Usa datos ficticios, como el cliente *Empresa Demo S.A.*
3. Guarda la evidencia junto al caso.
